# sHome for Home Assistant

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)](https://github.com/hacs/integration)


삼성SDS/직방 **IHP(sHome)** 월패드용 Home Assistant 커스텀 통합.
클라우드 REST API(`shome-api.samsung-ihp.com`)를 그대로 사용해 로컬 배선 없이 아파트 월패드 기기와 데이터를 연동한다.
로컬에 배선을 건드리지 않고 계정 자격증명만으로 동작한다.

## 지원 기능

| 도메인 | sHome 기기 | 기능 |
|--------|-----------|------|
| `light` | 조명(jm), 디밍(dm) | 켜기/끄기, 디밍 밝기 |
| `climate` | 난방(bl/br), 냉방(aircon) | 전원, 현재/희망 온도 |
| `fan` | 환기(vf) | 켜기/끄기, 풍량 |
| `cover` | 커튼(ct) | 열기/닫기/정지 |
| `valve` | 가스밸브(gv) | 닫기(안전상 원격 열기 불가) |
| `switch` | 퇴실스위치(os) | 일괄소등 |
| `select` | 홈모드 | 외출/재실/방범 등 전환 |
| `sensor` | 에너지 | 전기/수도/가스/온수/난방 사용량, 관리비 |
| `sensor`* | 실내환경(환경센서) | 온도/습도/CO2/미세먼지 (레거시 세대, 실험적) |
| `switch`* | 스마트콘센트(대기전력) | 콘센트 on/off (레거시 세대, 실험적) |

### 세대 유형에 따른 지원 범위

로그인 시 `isMhpsUser`로 세대가 갈린다.

- **MHPS 세대** (`isMhpsUser=1`, 신형): 위 표의 `*` 없는 항목 전부 — **구현·라이브 검증 완료.**
  이 세대의 sHome 클라우드 API에는 실내환경/스마트콘센트 등이 노출되지 않는다(월패드 로컬에만 존재).
- **레거시 세대** (`isMhpsUser=0`, 구형): `/v16·/v18/settings/*` 계열 사용. `*` 표시 항목(실내환경 센서, 스마트콘센트)을
  **실험적으로 구현**했으나, 개발용 계정이 MHPS라 **라이브 검증 불가** — 해당 세대 사용자의 테스트·피드백이 필요하다.
  시스템에어컨·보안센서·레거시 조명/난방 제어는 아직 미구현.

## 설치 (HACS 커스텀 저장소)

1. HACS → 통합(Integrations) → 우측 상단 ⋮ → **Custom repositories**.
2. 저장소 `https://github.com/ripe-avocado/shome_ha`, 카테고리 **Integration** 추가.
3. 목록에서 **sHome** 설치 후 Home Assistant 재시작.
4. **설정 → 기기 및 서비스 → 통합 추가 → "sHome"** 에서 아이디/비밀번호 입력.

또는 아래처럼 수동 설치:

### 수동 설치

1. 이 저장소의 `custom_components/shome/` 폴더를 HA 설정 디렉터리의 `config/custom_components/shome/` 로 복사.
2. Home Assistant 재시작.
3. **설정 → 기기 및 서비스 → 통합 추가 → "sHome"** 검색.
4. sHome **아이디**(전화번호 등)와 **비밀번호** 입력.
   - 비밀번호는 SHA-512로 해시되어 전송되며, HA는 평문을 config entry에 저장한다.
   - 로그인 시 임의의 16자리 기기ID(`mobileDeviceIdno`)를 1회 생성해 고정 사용한다.

## 주의사항

- **로그인 잠금**: 비밀번호를 5회 틀리면 계정이 ~10분 잠기고, 잠긴 동안 로그인을 재시도하면 타이머가 리셋된다.
  통합은 잠금 감지 시 자동 재시도를 멈추고 백오프한다. 앱에 잘못된 비밀번호가 저장돼 자동 재시도 중이면
  앱을 강제종료하고 올바른 비밀번호로 1회 로그인해 잠금을 해제한 뒤 통합을 설정하라.
- **폴링 주기**: 기본 60초(`cloud_polling`). 실시간 push(MQTT)는 향후 과제.
- **가스밸브**: 안전상 원격 열기는 지원하지 않으며 닫기만 가능하다.
- 본 통합은 개인의 자택 계정 연동용 비공식 프로젝트다.

## 개발용 프로브

자격증명으로 로그인/조회를 즉시 확인:

```bash
python3 tools/shome_probe.py --id <아이디> --pw <비밀번호> --json
```
